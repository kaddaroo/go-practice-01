## 3. Выполненные задания

### 3.1. Первая программа

Создана консольная программа, выводящая приветствие.

Изучены:
- `package main` и `func main()`;
- импорт пакетов;
- `fmt.Println`;
- команды `go run` и `go build`;
- компиляция и запуск исполняемых файлов.

### 3.2. Карточка участника

Программа выводит сведения об участнике курса.

Использованы:
- `var`, `:=`, `const`;
- типы `string`, `int`, `bool`;
- форматированный вывод `fmt.Printf`;
- соглашение об именовании `camelCase`.

### 3.3. Конвертер минут

Программа считывает целое количество минут и вычисляет полные часы и оставшиеся минуты.

Основные операции:

```go
hours := minutes / 60
remainingMinutes := minutes % 60
```

Реализованы проверка корректности ввода, обработка ошибок и отклонение отрицательных значений.

### 3.4. Эксперименты с синтаксисом

Создана отдельная программа для изучения базовых возможностей Go.

Использованы переменные, константы, типы `string`, `int`, `bool`, `float64`, арифметические выражения и форматированный вывод.

### 3.5. Среднее арифметическое (дополнительно)

Программа вычисляет сумму трёх целых чисел и их среднее арифметическое.

Для сохранения дробной части выполняется преобразование в `float64` до деления.

Результат выводится с двумя знаками после десятичной точки.
